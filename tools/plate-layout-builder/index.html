    Selection guide

    Click a well, or drag across wells to select them. Hold Shift, Command or Ctrl to add wells; a modified click toggles a well. Row and column labels select the whole row or column. On touchscreens, tap wells and swipe to scroll the plate.

    Keyboard: arrows move focus. Space toggles the focused well; Enter selects it. Shift, Command or Ctrl with Enter adds or removes it. Home/End moves to the row ends; Command/Ctrl with Home/End moves to the plate ends. Command/Ctrl+A selects all; Escape clears selection.

    Export / Bench view

    Export the complete plate, one row per well. Select the matching plate size in Growth Curve Analyser before importing. Bench view opens a white-paper layout for Print / Save as PDF.

    Your layout stays in this browser session. Refreshing closes the current workspace.

    A4 landscape at 100% scale. Turn off browser headers/footers. The 384-well map uses two row bands; long assignment keys continue on extra pages. Letter/line patterns remain readable in grayscale.

    Open Bench view, review the current plate, then choose Print / Save as PDF.

    Review output

    The metadata contains exactly well, strain, condition, replicate_id, role, blank_group in that order. Every plate well is included; well-only rows clear existing metadata on analyser import. Planning codes are not exported.
